# Life hub — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformar o painel Life num hub de apps (trilho lateral) com Diary, Finances e AI usage dentro, em inglês,
com rotas por app, links cruzados e a barra lateral do Odysseus com um item por app.

**Architecture:** `static/js/life/router.js` (puro) define as rotas `#life/<app>/…`; `static/js/life/index.js` vira a
moldura do hub (janela, trilho, cabeçalho, busca, barra lateral, lista de apps no celular) e monta apps registrados
em `static/js/life/apps.js`. O Diary sai de `index.js` para `static/js/life/apps/diary.js`. `static/js/finance.js` e
`static/js/aiUsage.js` perdem a janela própria e passam a exportar `mountFinances` / `mountAiUsage`, carregados sob
demanda por adaptadores finos.

**Tech Stack:** JS ES modules sem build, CSS; `node --test`; pytest para os testes estáticos; Chromium headless no
container para a checagem visual.

**Spec:** `docs/superpowers/specs/2026-11-07-life-hub-design.md`

## Global Constraints

- Textos da UI em **inglês**; comentários e commits em **português**. Dados (categorias de Finanças, descrições de
  transações, títulos de sessões) ficam como estão.
- Datas `dd/mm/yyyy` com `toLocaleString('en-GB', …)` / números com separador de milhar em vírgula
  (`R$ 1,234.56`) — nada de `'pt-BR'` nos módulos tocados.
- Rotas: `#life/diary/<YYYY-MM-DD|YYYY-MM|YYYY>`, `#life/diary/search?q=`, `#life/finances/<tab>[?from=&to=&account=&q=]`,
  `#life/ai/<tab>[?from=&to=]`; hashes antigos `#life/<data|mês|ano>` e `#life/search?q=` abrem o Diary. Links
  internos sempre por `lifeHref(app, path, params)`.
- Abas Finances: `overview, monthly, review, categories, transactions, audit, files`. Abas AI usage:
  `overview, models, sessions, calendar, tools, limits, web, code` (as chaves que já existem em `TABS`).
- Escopo de CSS: regras novas só sob `#life-panel` ou classes `.life-*`/`.fin-*`/`.aiu-*`; cores só por tokens do
  tema (`--life-accent` segue `--red`).
- Cache: ao mexer em CSS do fork, o **token compartilhado** `?v=` das folhas (hoje `20261021confirmalign1`) muda em
  TODAS as ocorrências de `static/index.html` e `static/sw.js` (é um token só, inclusive o de `app.js`); `CACHE_NAME`
  casa `odysseus-v<N>-pr40-editor-precache` (bump só de N); o `?v=` de `static/js/life/index.js` no `index.html` sobe.
- Nada de backend nesta entrega. Nada de upstream além de `static/index.html` e `static/sw.js`.
- Testes: `./venv/bin/python -m pytest -q -p no:cacheprovider <arquivos>`; `node --test <arquivo>`;
  `for f in static/js/life/*.js static/js/life/apps/*.js static/js/finance.js static/js/aiUsage.js; do node --check "$f" || exit 1; done`.

```js
// static/js/life/router.js — rotas do hub Life: #life/<app>/<caminho>?<params> (puro; tests/life_router.test.mjs).
// Hashes antigos do Diary (#life/AAAA-MM-DD, #life/AAAA-MM, #life/AAAA, #life/search?q=) continuam valendo.
export const APP_IDS = ['diary', 'finances', 'ai'];
const DIARY_LEGACY = /^(\d{4}-\d{2}-\d{2}|\d{4}-\d{2}|\d{4}|search)$/;

export function parseLifeHash(hash) {
  const s = String(hash || '').replace(/^#/, '');
  if (s !== 'life' && !s.startsWith('life/') && !s.startsWith('life?')) return null;
  const rest = s.slice(4).replace(/^\//, '');
  const qi = rest.indexOf('?');
  const pathStr = qi >= 0 ? rest.slice(0, qi) : rest;
  const params = Object.fromEntries(new URLSearchParams(qi >= 0 ? rest.slice(qi + 1) : ''));
  const parts = pathStr.split('/').filter(Boolean).map(decodeURIComponent);
  if (!parts.length) return { app: null, path: [], params };
  if (DIARY_LEGACY.test(parts[0])) return { app: 'diary', path: parts, params };
  if (!APP_IDS.includes(parts[0])) return { app: null, path: [], params: {} };
  return { app: parts[0], path: parts.slice(1), params };
}

export function lifeHref(app, path = [], params = {}) {
  const segs = [app, ...(Array.isArray(path) ? path : [path])].filter(x => x != null && x !== '').map(encodeURIComponent);
  const q = new URLSearchParams(Object.entries(params).filter(([, v]) => v != null && v !== '')).toString();
  return `#life/${segs.join('/')}${q ? `?${q}` : ''}`;
}
```

```js
// static/js/life/apps/diary.js — app Diary do hub Life: dia, mês, ano e busca (visões em ../day.js, ../month.js,
// ../year.js, ../search.js, que recebem o mesmo ctx de antes: {st, go(patch, opts), api, isCurrent}).
import { api, isAbort } from '../api.js';
import { escapeHtml, fmtDate, monthName, shiftDay, shiftMonth } from '../format.js';
import { icon } from '../icons.js';
import { emptyState, skeleton } from '../parts.js';
import { renderDay } from '../day.js';
import { renderMonth } from '../month.js';
import { renderYear } from '../year.js';
import { renderSearch } from '../search.js';

const VIEWS = { day: renderDay, month: renderMonth, year: renderYear, search: renderSearch };
const LS_KEY = 'odysseus.life.v1';
const DAY_RE = /^\d{4}-\d{2}-\d{2}$/;
const MONTH_RE = /^\d{4}-\d{2}$/;
const YEAR_RE = /^\d{4}$/;

export async function mountDiary(host, hub) {
  const st = { view: 'day', day: '', q: '', metric: 'digital', filter: 'all', kinds: '', from: '', to: '', focus: '', meta: null };
  try {
    const s = JSON.parse(localStorage.getItem(LS_KEY) || '{}');
    if (DAY_RE.test(s.day || '')) st.day = s.day;
    if (typeof s.metric === 'string') st.metric = s.metric;
  } catch (_) { /* armazenamento indisponível */ }
  let seq = 0;
  host.classList.add('life-body');
  host.tabIndex = -1;
  const bar = hub.setToolbar(`
    <nav class="life-crumbs" aria-label="Zoom level"></nav>
    <div class="life-nav">
      <button type="button" class="life-icon-btn" data-act="prev" aria-label="Previous" title="Previous (←)">${icon('chevron-left')}</button>
      <button type="button" class="life-btn" data-act="today" title="Today (t)">Today</button>
      <button type="button" class="life-icon-btn" data-act="next" aria-label="Next" title="Next (→)">${icon('chevron-right')}</button>
    </div>`);
  const crumbsEl = bar.querySelector('.life-crumbs');
  const navEl = bar.querySelector('.life-nav');

  const persist = () => { try { localStorage.setItem(LS_KEY, JSON.stringify({ day: st.day, metric: st.metric })); } catch (_) {} };
  const todayIso = () => st.meta?.today || new Date().toISOString().slice(0, 10);
  const pathOf = () => (st.view === 'search' ? ['search'] : st.view === 'month' ? [st.day.slice(0, 7)]
    : st.view === 'year' ? [st.day.slice(0, 4)] : [st.day]);
  const paramsOf = () => (st.view === 'search' ? { q: st.q } : {});
  function go(patch = {}, opts = {}) {
    Object.assign(st, patch);
    if (!st.day) st.day = todayIso();
    hub.navigate(pathOf(), paramsOf(), opts);
  }
  function step(n) {
    if (st.view === 'day') go({ day: shiftDay(st.day, n) });
    else if (st.view === 'month') go({ day: `${shiftMonth(st.day.slice(0, 7), n)}-01` });
    else if (st.view === 'year') go({ day: `${Number(st.day.slice(0, 4)) + n}-01-01` });
  }
  function zoomOut() {
    if (st.view === 'day') go({ view: 'month' });
    else if (st.view === 'month') go({ view: 'year' });
  }
  const goToday = () => go({ view: st.view === 'search' ? 'day' : st.view, day: todayIso() });

  function crumbs() {
    const y = st.day.slice(0, 4);
    const m = Number(st.day.slice(5, 7));
    const d = Number(st.day.slice(8, 10));
    const b = (view, label) => `<button type="button" data-view="${view}"${st.view === view ? ' class="is-current" aria-current="page"' : ''}>${label}</button>`;
    const sep = '<span class="life-crumb-sep" aria-hidden="true">›</span>';
    crumbsEl.innerHTML = st.view === 'search'
      ? `${b('day', `${icon('chevron-left', 13)}${escapeHtml(fmtDate(st.day))}`)}${sep}<span class="is-current">Search</span>`
      : [b('year', y), st.view !== 'year' ? b('month', monthName(m)) : '', st.view === 'day' ? b('day', String(d)) : '']
        .filter(Boolean).join(sep);
    navEl.hidden = st.view === 'search';
  }

  async function render() {
    const mine = ++seq;
    crumbs();
    host.setAttribute('aria-busy', 'true');
    host.innerHTML = skeleton(st.view);
    host.scrollTop = 0;
    const ctx = { st, go, api, isCurrent: () => mine === seq && hub.isCurrent() };
    try {
      await VIEWS[st.view](host, ctx);
    } catch (e) {
      if (isAbort(e) || mine !== seq) return;
      host.innerHTML = emptyState('other', 'Could not load this view', escapeHtml(e.message));
    } finally {
      if (mine === seq) host.removeAttribute('aria-busy');
    }
  }

  navEl.addEventListener('click', e => {
    const b = e.target.closest('[data-act]');
    if (!b) return;
    if (b.dataset.act === 'today') goToday();
    else step(b.dataset.act === 'next' ? 1 : -1);
  });
  crumbsEl.addEventListener('click', e => {
    const b = e.target.closest('[data-view]');
    if (b) go({ view: b.dataset.view });
  });

  try {
    st.meta = await api('meta', {}, { key: 'diary-meta' });
  } catch (e) {
    if (!isAbort(e)) host.innerHTML = emptyState('life', 'Diary is not available', escapeHtml(e.message));
  }

  return {
    route(path, params) {
      const p = path[0] || '';
      if (!p) { if (!st.day) st.day = todayIso(); hub.navigate(pathOf(), paramsOf(), { replace: true }); return undefined; }
      if (p === 'search') Object.assign(st, { view: 'search', q: params.q || '' });
      else if (DAY_RE.test(p)) Object.assign(st, { view: 'day', day: p });
      else if (MONTH_RE.test(p)) Object.assign(st, { view: 'month', day: st.day.startsWith(p) ? st.day : `${p}-01` });
      else if (YEAR_RE.test(p)) Object.assign(st, { view: 'year', day: st.day.startsWith(p) ? st.day : `${p}-01-01` });
      else Object.assign(st, { view: 'day', day: st.day || todayIso() });
      if (!st.day) st.day = todayIso();
      persist();
      return render();
    },
    onKey(e) {
      const typing = e.target.closest?.('input, textarea, select, [contenteditable="true"]');
      if (typing || e.altKey || e.ctrlKey || e.metaKey || e.shiftKey) return;
      if (e.key === 'ArrowLeft' && st.view !== 'search') { e.preventDefault(); step(-1); }
      else if (e.key === 'ArrowRight' && st.view !== 'search') { e.preventDefault(); step(1); }
      else if (e.key === 'ArrowUp' && host.scrollTop === 0 && (st.view === 'day' || st.view === 'month')) { e.preventDefault(); zoomOut(); }
      else if (e.key === 't') goToday();
    },
    unmount() { seq += 1; },
  };
}
```

```js
const LS_KEY = 'odysseus.life.hub.v1';
const NARROW = '(max-width: 640px)';
const memory = { app: 'diary', routes: {} };

let current = null;

  try {

  lastHash = '';
}

function showIndex(on) {
  els.panel.classList.toggle('is-index', !!on);
  if (on) markRail(null);
}

function markRail(id) {
  els.rail.querySelectorAll('[data-app]').forEach(a => {
    const on = a.dataset.app === id;
    a.classList.toggle('is-current', on);
    if (on) a.setAttribute('aria-current', 'page'); else a.removeAttribute('aria-current');
  });
}

function hubFor(id) {
  return {
    lifeHref,
    navigate: (path = [], params = {}, opts = {}) => go(lifeHref(id, path, params), opts),
    open: (href, opts = {}) => go(href, opts),
    setToolbar(html) { els.toolbar.innerHTML = html; return els.toolbar; },
    isCurrent: () => current?.id === id,
  };
}

function go(href, { replace = false } = {}) {
  if (!parseLifeHash(location.hash)) returnHash = location.hash;
  if (location.hash !== href) {
    try { history[replace ? 'replaceState' : 'pushState'](null, '', href); } catch (_) { location.hash = href; }
  }
  lastHash = href;
  return apply(parseLifeHash(href));
}

function apply(r) {
  queue = queue.then(() => doApply(r)).catch(e => console.error('life:', e));
  return queue;
}

async function doApply(route) {
  let r = route || { app: null, path: [], params: {} };
  if (!r.app) {
    if (narrow()) { showIndex(true); return; }
    const href = memory.routes[memory.app] || lifeHref(memory.app);
    try { history.replaceState(null, '', href); } catch (_) {}
    lastHash = href;
    r = parseLifeHash(href);
  }
  const app = appById(r.app) || APPS[0];
  showIndex(false);
  if (!current || current.id !== app.id) {
    try { current?.inst?.unmount?.(); } catch (_) {}
    els.host.innerHTML = '';
    els.toolbar.innerHTML = '';
    const host = document.createElement('div');
    host.className = `life-app life-app-${app.id}`;
    els.host.append(host);
    current = { id: app.id, inst: null };
    els.title.textContent = app.label;
    els.panel.dataset.app = app.id;
    markRail(app.id);
    try {
      current.inst = await app.mount(host, hubFor(app.id));
    } catch (e) {
      host.innerHTML = emptyState('other', `Could not open ${app.label}`, escapeHtml(e.message));
      current.inst = { route() {}, unmount() {} };
    }
  }
  memory.app = app.id;
  memory.routes[app.id] = parseLifeHash(location.hash)?.app === app.id ? location.hash : lifeHref(app.id, r.path, r.params);
  persist();
  try { await current.inst.route(r.path, r.params); } catch (e) { console.error('life route:', e); }
}

function onKey(e) {
  const typing = e.target.closest?.('input, textarea, select, [contenteditable="true"]');
  if ((e.key === '/' && !typing) || ((e.ctrlKey || e.metaKey) && e.key.toLowerCase() === 'k')) {
    e.preventDefault();
    els.input.focus();
    els.input.select();
    return;
  }
  current?.inst?.onKey?.(e);
}

function openApp(id) {
  return go(memory.routes[id] || lifeHref(id));
}

function openPanel({ app = null } = {}) {
  buildPanel();
  els.panel.classList.remove('hidden');
  raise();
  if (app) return openApp(app);
  const r = parseLifeHash(location.hash);
  if (r) { lastHash = location.hash; return apply(r); }
  return go(memory.routes[memory.app] || lifeHref(memory.app));
}

function fromHash() {
  const r = parseLifeHash(location.hash);
  if (!r) return;
  if (location.hash === lastHash && isOpen()) return;
  lastHash = location.hash;
  buildPanel();
  if (!isOpen()) { els.panel.classList.remove('hidden'); raise(); }
  apply(r);
}

function mountSidebar() {
  const list = document.getElementById('lifelog-list');
  if (!list || list.dataset.ready) return;
  list.dataset.ready = '1';
  for (const a of APPS) {
    const item = document.createElement('div');
    item.className = 'list-item life-side-item';
    item.dataset.app = a.id;
    item.innerHTML = `${icon(a.icon, 14)}<span class="grow">${escapeHtml(a.label)}</span>`;
    item.addEventListener('click', () => openPanel({ app: a.id }));
    list.append(item);
  }
}

restore();
window.addEventListener('hashchange', fromHash);
window.addEventListener('popstate', fromHash);
function boot() {
  mountSidebar();
  if (parseLifeHash(location.hash)) fromHash();
}
if (document.readyState === 'loading') document.addEventListener('DOMContentLoaded', boot);
else boot();

export { openPanel };
```
